PSWKT Laboratoire de tests WebKit

Diagnostic d'API JavaScript — du sondage doux et reproductible au stress test agressif qui pousse le moteur jusqu'a la rupture. Pense pour le navigateur WebKit de la PS5 (13.60) et tout WebKit.

Fonctionnalites reellement disponibles

Vert = presente, gris = absente. Les tests dependant d'une API absente seront automatiquement ignores.

2. Garde-fous de ressources

Ces limites cadrent les tests ordinaires. Les tests agressifs (destructifs) les ignorent volontairement : ils poussent les API jusqu'a la rupture.

3. Categories de tests

Cochez les tests a executer, lancez une categorie entiere, ou un test isole.

4. Resultats en direct

5. Journal d'execution

Chaque test ecrit ici son debut, ses sous-etapes, ses mesures et sa fin. Les erreurs JS globales y apparaissent aussi. Copiez tout le journal pour l'analyser sur PC.

6. Export du rapport

Le rapport inclut l'environnement, les fonctionnalites, tous les resultats, les durees et les erreurs JS. Sur console, utilisez la zone de texte si le telechargement echoue.

7. Historique des sessions

Chaque lancement cree une nouvelle session enregistree localement dans le navigateur (IndexedDB) — aucun serveur requis, compatible hebergement statique. Consultez, exportez (JSON/TXT), comparez ou supprimez vos sessions.

PSWKT — tests reproductibles et non destructifs. Une erreur JavaScript observee ici est un comportement a documenter, pas une vulnerabilite. Pour des diagnostics memoire approfondis, utilisez un WebKit instrumente sur PC.
