About this tool

PSWKT is a non-persistent JavaScript / WebKit diagnostic and robustness lab. It maps which APIs are really available, checks behaviours, and — in aggressive mode — stress-tests the engine to its limits. A JavaScript error observed here is a behaviour to document, not a finding.

Aggressive tests can freeze or crash the browser tab. Many such crashes are simply the browser hitting its normal resource limits. A sandboxed browser strongly limits risk, but no guarantee of « no possible consequence » can be made — in practice the worst case is the tab dying and the console restarting. Local saving (IndexedDB) is best-effort: the per-test start marker is written before each test, but each result is saved asynchronously, so a brutal crash can still lose the last result(s).
